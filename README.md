# 🌟 Aprende Kichwa con ALY

Aprende Kichwa con ALY es una aplicación web educativa para niños de 7 años que aprenden Kichwa del Ecuador desde cero.

> «Kichwa se aprende por amor, no por imposición»

---

## 📌 Sobre el Proyecto
- **Creadora:** Rosa Cecilia de Jesús Arias
- **Personaje Principal:** ALY
- **Público Objetivo:** Niños de 7 años y principiantes
- **Idioma:** Español con vocabulario progresivo en Kichwa

---

## 🚀 Qué incluye esta aplicación
1. **Pronombres y Conjugación:** Juego interactivo del verbo KANA (ser/estar).
2. **Constructor de Oraciones:** Fichas interactivas para ordenar palabras.
3. **Juegos y Retos:** Preguntas con estrellas y felicitaciones.

---

## 💻 Cómo usar
Abre el archivo `index.html` en el navegador de tu computadora, tableta o teléfono para jugar.
